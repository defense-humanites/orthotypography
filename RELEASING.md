# Releasing orthotypography

Publication is disabled until the first prerelease is explicitly approved.

Both registries use `@orthotypography/core` and the version declared in `deno.json`. JSR publishes the TypeScript source directly; npm receives the ESM package generated by `@deno/dnt`.

Before enabling publication:

1. create and link the package on JSR ;
2. configure npm trusted publishing for `.github/workflows/publish.yml` and the `release` environment ;
3. protect the GitHub `release` environment and restrict its tags ;
4. leave `PUBLISH_ENABLED` absent or equal to `false`.

For a prerelease, run `deno task check`, `deno task test`, `deno task publish:check`, and `deno task npm:check`; tag the exact version with a `v` prefix; then enable `PUBLISH_ENABLED` only for the authorized publication window.
